Use your own auth token (optional)

By default this app reads public data with a built-in service token, so most users need nothing here. Only add your own token to reach data the service account can't (e.g. private datasets). It's a middleauth Bearer token, stored only in this browser (localStorage), and takes precedence over the built-in one. Get a token.

What do the columns mean?
ColumnMeaning
sourceState id (or link) the row came from — distinguishes annotations when several links are combined.
layerName of the annotation layer in the neuroglancer state.
annotation_idThe annotation's id within neuroglancer.
typepoint, line, ellipsoid, or axis_aligned_bounding_box.
ax, ay, azFirst point: the point (for points), pointA (lines / boxes), or center (ellipsoids), in the state's coordinate space.
bx, by, bzSecond point: pointB (lines / boxes) or radii (ellipsoids). Blank for single-point annotations.
distance_nativeEuclidean distance between the two points in raw coordinate (voxel) units. Two-point annotations only.
distance_nmSame distance in nanometers, using the voxel resolution below. Two-point annotations only.
resolution_nm_per_voxelVoxel size of the state's coordinate space, e.g. 4 x 4 x 40 (nm/voxel). Same for every row from a given state; this is the factor relating the coordinate columns to nanometers.
descriptionFree-text description attached to the annotation.
segmentsLinked segment ids, space-separated.
prop_<name>One column per local annotation property. Enum-valued properties show their label rather than the numeric code.
